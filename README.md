# BookVerse Foundation Landing Page

Landing page berbasis React, Tailwind CSS, dan Lucide Icons untuk BookVerse Foundation.

## Cara Menjalankan Preview

### Opsi 1: Klik Ganda (Windows)
Cukup klik ganda file `run-preview.bat`.

### Opsi 2: Menggunakan Terminal / Command Prompt
Jalankan perintah berikut:
```bash
npm.cmd run dev
```

Buka browser dan akses alamat:
```
http://localhost:3000/
```

## Fitur yang Diterapkan
- **Hero Section**: Profil, deskripsi singkat, tombol media sosial (Instagram, TikTok, Google Maps), dan tombol CTA kolaborasi.
- **Tentang Kami & Sejarah**: Informasi visi misi dan timeline perkembangan BookVerse.
- **Katalog Koleksi**: Slider koleksi buku lengkap dengan modal Lightbox interaktif.
- **Info Layanan**: Jam operasional dan fasilitas.
- **Tanya Jawab (FAQ)**: Accordion interaktif untuk pertanyaan umum.
- **Kisah Pembaca (Testimonial)**: Review dan testimoni pengunjung.
- **Formulir Kontak**: Formulir langsung terhubung ke pesan WhatsApp pengelola.
- **Modal Bagikan (Share)**: Opsi bagikan ke X, Facebook, WhatsApp, serta fitur salin tautan.
- **Sticky CTA**: Tombol mengambang di bawah untuk akses cepat ke formulir kolaborasi.
